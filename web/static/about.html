О проекте

Shelfmate — социальная сеть для тех, кто любит читать. Отмечайте прочитанные книги, ставьте оценки от 1 до 100, пишите рецензии и следите за своей читательской статистикой. Проект сделан по мотивам Letterboxd — только для книг.

Что уже работает

  • каталог из более чем тысячи книг с поиском по названию;
  • страницы книг с оценками и рецензиями читателей;
  • профили читателей: полка, активность и личная статистика;
  • общая статистика сервиса и регистрация.

Как добавить книгу на полку

Кнопки на сайте появятся в следующей версии. Пока полкой, оценками и рецензиями управляет REST API — его документация открывается прямо в браузере.

Как это устроено

Бэкенд — Go и PostgreSQL, он отдаёт данные через JSON API. Страницы — обычный HTML, а данные в них подгружает JavaScript. Обложки книг рисуются средствами CSS — картинок в базе нет.
